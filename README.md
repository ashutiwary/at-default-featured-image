# AT Default Featured Image

A WordPress plugin that automatically adds a default featured image for posts that don't have one set.

## Description

AT Default Featured Image provides a simple solution to ensure all your posts have featured images. When a post doesn't have a featured image set, the plugin will display a default image of your choice instead of leaving the space empty.

### Key Features

- Set a custom default featured image
- Enable/disable the feature through settings
- Uses native WordPress media library for image selection
- Comes with a default SVG placeholder image
- Easy to configure through WordPress admin interface

## Installation

1. Upload the `at-default-featured-image` folder to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to Settings > Default Featured Image to configure the plugin

## Configuration

1. Navigate to Settings > Default Featured Image in your WordPress admin panel
2. Check/uncheck "Enable Default Featured Image" to toggle the feature
3. Click "Choose Image" to select a custom default image
4. Use "Reset to Default" to revert to the built-in placeholder image
5. Click "Save Changes" to store your settings

## Usage

Once activated and configured, the plugin works automatically:

- Posts with featured images will display their set images normally
- Posts without featured images will display your chosen default image
- No changes to your theme code are required

## Requirements

- WordPress (Latest version recommended)
- PHP 5.6 or higher
